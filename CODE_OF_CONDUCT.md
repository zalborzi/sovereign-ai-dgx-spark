# Code of Conduct

## Our commitment

We want this project to be a welcoming, respectful, and useful space for people interested in local AI, DGX Spark, Kubernetes, vLLM, Open WebUI, and sovereign AI demos.

Contributors and participants are expected to help create a professional, inclusive, and harassment-free environment.

## Expected behavior

Examples of behavior that contributes to a positive environment:

- Be respectful and constructive.
- Assume good intent, but be clear when something is wrong or unsafe.
- Give technical feedback without personal attacks.
- Keep discussions focused on the project.
- Be patient with people learning Kubernetes, GPU workloads, LLM serving, or Open WebUI.
- Respect different levels of experience.
- Avoid sharing secrets, private tokens, customer data, or confidential information.

## Unacceptable behavior

Examples of unacceptable behavior include:

- Harassment, intimidation, insults, or personal attacks.
- Discriminatory language or behavior.
- Trolling, repeated off-topic comments, or deliberate disruption.
- Publishing private information without permission.
- Sharing real secrets, access tokens, private customer data, or confidential business data.
- Encouraging unsafe deployment practices without clear warnings.
- Misrepresenting synthetic demo data as real financial, customer, or production data.

## Project-specific expectations

This repository includes demo material related to:

- local LLM inference
- Open WebUI tools
- RAG access control
- synthetic finance data
- weather tool-calling
- Kubernetes and GPU manifests

Contributors must keep demo data synthetic. Do not contribute real customer data, real finance data, real secrets, private keys, production credentials, or internal company documents.

Open WebUI tools execute Python code on the server. Tool contributions must be reviewed carefully and must not include destructive commands, credential exfiltration, hidden network calls, or unsafe execution patterns.

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, pull requests, or contributions that violate this Code of Conduct.

Maintainers may temporarily or permanently restrict participation for behavior that is harmful to the project or community.

## Reporting

To report unacceptable behavior, contact the project maintainer through GitHub.

For security vulnerabilities, do not open a public issue. Follow the instructions in [`SECURITY.md`](SECURITY.md).
